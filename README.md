# QR-Помощник

Сервис для мелких предпринимателей: заказ наклеек с QR-кодами (визитка/vCard,
Wi-Fi, соцсети, отзывы в Google, «сканируй и звони», оплата на карту и т.д.)
с конструктором шаблонов и отправкой макетов на производство.

Полная расшифровка идеи и структура страниц — в [docs/spec.md](docs/spec.md).

## Стек

React + Node, которые уже знакомы, — этого достаточно. Ничего нового учить
не нужно, но собирать лучше не «голый React + Express», а **Next.js** — это
тот же React, только со встроенным сервером (Node), роутингом и SSR.

| Слой | Выбор | Почему |
|------|-------|--------|
| Фреймворк | **Next.js (App Router) + TypeScript** | Маркетинговый сайт должен индексироваться Google → нужен SSR/SSG. Фронт и API-роуты в одном проекте, деплой одним куском. |
| i18n (укр/рус) | **next-intl** | Переключатель языка из макета, локализованные URL (`/ua`, `/ru`). |
| БД | **SQLite (старт) → PostgreSQL** через **Prisma** | Заказы, данные клиентов, статусы производства. SQLite хватит до первых реальных объёмов, миграция на Postgres через Prisma безболезненна. |
| QR-генерация | пакет **`qrcode`** | Генерит SVG/PNG. Все типы наклеек — это просто разные payload-форматы: URL, `tel:`, `mailto:`, `sms:`, `WIFI:T:WPA;S:имя;P:пароль;;`, vCard 3.0. Отдельных сервисов не нужно. |
| Печатные макеты | SVG-шаблоны → PDF/PNG 300 dpi (`sharp` или `@resvg/resvg-js`) | Шаблон наклейки — SVG с плейсхолдерами (QR, текст, цвета из конструктора). Раскладка мелких шаблонов на общий лист для производства — тоже SVG-композиция. |
| Оплата | **LiqPay** (Приват24) или **WayForPay / Fondy / monobank-эквайринг** | Stripe в Украине недоступен. LiqPay логичен, раз в эскизах фигурирует Приват24. |
| Формы | react-hook-form + zod | Большая форма заказа с валидацией по типам полей (URL, телефон, email, номер карты). |
| Деплой | VPS + nginx + Let's Encrypt (или Vercel) | Покупать Comodo SSL из записей не нужно — Let's Encrypt бесплатный. |

## Почему не что-то другое

- **Отдельный бэкенд (Nest/Express) не нужен**: логики немного — заказы,
  генерация QR/макетов, платёжный вебхук. API-роутов Next.js достаточно.
  Если появится админка производства и объёмы — вынести API можно позже.
- **WordPress/Tilda** быстрее для витрины, но конструктор наклеек и
  генерация печатных листов — кастомный код, там его писать больнее.
- **Мобильное приложение** (п. 12 из записей) на старте не нужно — весь
  сценарий клиента работает через камеру телефона.

## Порядок работы (MVP)

1. Каркас Next.js + i18n + 4 страницы: главная, «Как это работает»,
   «Вопросы и ответы», «Заказать наклейки».
2. Генерация QR по всем типам payload + предпросмотр наклейки в браузере.
3. Форма заказа → сохранение заказа в БД → оплата (LiqPay sandbox).
4. Конструктор цветов (текст/фон/рамка/QR) для индивидуального шаблона.
5. Генерация печатного листа (раскладка макетов) для производства.
